# Software Design Patterns Final Project

Командный проект Асанали, Амира, Бакытжана и Рустама по курсу Software Design Patterns.

**Состояние:** репозиторий подготовлен для совместной работы. Тема, язык (Java или Go) и реализация приложения утверждаются на этапе Асанали. Если у команды уже есть проект, его код добавляется сюда без смены темы. Если темы ещё нет, рабочее предложение — **Event Studio**: создание мероприятия, настройка услуг, бронирование, изменение статуса и сохранение итоговой сводки.

## С чего начать

1. Прочитайте [требования](docs/REQUIREMENTS.md), [план](docs/PROJECT_PLAN.md) и [правила работы](CONTRIBUTING.md).
2. Найдите свою инструкцию в [TEAM_PROMPTS.md](TEAM_PROMPTS.md). Отправьте своему ИИ-чату общий блок и блок своего этапа.
3. Работайте по очереди: **Асанали → Амир → Бакытжан → Рустам**. Каждый начинает после слияния PR предыдущего участника.
4. Перед передачей работы обновите [HANDOFF.md](docs/HANDOFF.md).

## Запуск

Команды установки, запуска и тестов будут добавлены Асанали после выбора языка и стека. Не считайте проект готовым к запуску, пока эти команды не проверены на чистом клоне.

## Итоговая сдача

Исходный код в ZIP, ссылка на GitHub, README с командами запуска, PDF-отчёт, диаграммы, тестовые сценарии и индивидуальная защита каждого участника.
